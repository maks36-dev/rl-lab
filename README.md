# RL — годовой курс: алгоритмы + инфраструктура

Монорепозиторий учебно-исследовательского курса по reinforcement learning.
Каждая глава — законченный проект: теория → игрушечный запуск → наблюдаемость и отладка →
масштабирование на несколько GPU → деплой → конспект и пост.

- Программа и критерии: [PLAN.md](PLAN.md)
- Код глав: `chapters/chNN_name/` (префикс `ch`: имя пакета Python не может начинаться с цифры)
- Результаты глав: `docs/NN_name/results.md`; готовые конспекты и посты добавляются туда по завершении главы, черновики — вне репо
- Общая библиотека: `rlcore/`

## Работа на сервере

Сервер общий (8× RTX A4000, ~30 пользователей). Перед запуском смотреть `scripts/gpu_free.sh`,
долгие процессы только в `tmux`, всё окружение в `.venvs/` (`source scripts/env.sh`), тяжёлые файлы и TensorBoard-логи в `runs/`, данные в `data/`.
